# Results & Grading System [toc]

NIOS results are prepared using the marks obtained in the various assessment
components applicable to a learner's stream and subject combination.

The components included in the final result depend on:

- Learner stream
- Subject type
- Examination mode
- Practical requirements

<Callout type="info">
  Not every learner has the same evaluation structure. Stream 1 learners
  generally have TMA and Formative Assessment components, while Stream 2, Stream
  3, Stream 4, and ODE learners follow different evaluation schemes.
</Callout>

## Assessment Components

<Cards>
  <Card title="Theory Examination">
    Written examinations conducted during Public Examinations or ODE.
  </Card>

<Card title="Tutor Marked Assignment (TMA)">
  Applicable to Stream 1 learners and contributes to theory evaluation.
</Card>

<Card title="Practical Examination">
  Practical assessments conducted for subjects with practical components.

  <Card title="Formative Assessment (FA)">
    Practical assessment component applicable to eligible Stream 1 learners.
  </Card>

## Stream 1 Result Structure

For Stream 1 learners, the result may include:

### Theory Subjects

| Component          | Weightage |
| ------------------ | --------: |
| Theory Examination |       80% |
| TMA                |       20% |

### Example

Suppose a subject contains:

| Component          | Marks |
| ------------------ | ----: |
| Theory Examination |    80 |
| TMA                |    20 |
| Total              |   100 |

If a learner scores:

| Component          | Marks Obtained |
| ------------------ | -------------: |
| Theory Examination |          60/80 |
| TMA                |          15/20 |
| Final Marks        |         75/100 |

<Callout type="info">
  TMA contributes 20% of the theory marks for Stream 1 learners.
</Callout>

## Stream 1 Practical Subjects

For eligible Stream 1 learners:

| Component                  | Weightage |
| -------------------------- | --------: |
| Formative Assessment (FA)  |       50% |
| Practical Examination (SA) |       50% |

### Example

Suppose a practical subject carries 20 practical marks.

| Component             | Marks |
| --------------------- | ----: |
| FA                    |    10 |
| Practical Examination |    10 |
| Total                 |    20 |

If a learner scores:

| Component             | Marks Obtained |
| --------------------- | -------------: |
| FA                    |           8/10 |
| Practical Examination |           7/10 |
| Final Practical Marks |          15/20 |

<Callout type="warning">
  Formative Assessment contributes 50% of the practical marks for eligible
  Stream 1 learners.
</Callout>

## Stream 2, Stream 3, Stream 4 & ODE Learners

Unlike Stream 1 learners, Stream 2, Stream 3, Stream 4, and ODE learners
generally do not have a TMA component or Formative Assessment component.

### Theory Subjects

| Component          | Weightage |
| ------------------ | --------: |
| Theory Examination |      100% |

### Practical Subjects

| Component             | Weightage |
| --------------------- | --------: |
| Practical Examination |      100% |

<Callout type="info">
  Results for Stream 2, Stream 3, Stream 4, and ODE learners are generally based
  entirely on the applicable examinations.
</Callout>

## Passing Criteria

To pass a subject, learners are generally required to obtain:

- At least 33% marks in theory.
- At least 33% marks in practicals where applicable.

<Callout type="warning">
  Passing requirements may vary depending on the subject and examination scheme.
  Always refer to the latest NIOS guidelines for official rules.
</Callout>

## Common Result Statuses

| Status         | Meaning                               |
| -------------- | ------------------------------------- |
| Pass           | Subject successfully cleared          |
| Failed         | Passing criteria not met              |
| AB             | Absent in the relevant component      |
| Result Awaited | Evaluation or processing pending      |
| UFM            | Unfair Means case under consideration |

### What Does AB Mean?

AB stands for **Absent**.

This may occur when a learner:

- Does not appear for an examination.
- Does not submit a TMA (Stream 1).
- Is absent in a practical examination.
- Is marked absent in Formative Assessment.

## Common Questions

### Why Are My Portal Marks Different From My Result Marks?

Certain marks may be scaled or adjusted during result processing.

Examples include:

- TMA marks being converted according to subject weightage.
- Practical marks being processed according to FA and SA rules.
- Stream-specific evaluation schemes.

### Does ODE Affect My Final Certification?

No.

Subjects passed through ODE carry the same academic value as subjects passed
through Public Examinations.

Certificates and marksheets do not distinguish between subjects cleared through
ODE and those cleared through Public Examinations.
