# What is TMA? [toc]

Tutor Marked Assignments (TMA) are home-based assignments issued by NIOS that
learners must complete and submit to their Study Centre (AI) for evaluation.

TMA is designed to encourage continuous learning and assess a learner's
understanding of the subject beyond examinations.

## Purpose of TMA

TMAs help learners:

- Study subjects regularly throughout the academic session.
- Develop writing and analytical skills.
- Reinforce concepts learned through self-study.
- Receive academic feedback from tutors.
- Contribute towards the final result.

<Callout type="info">
  Unlike Theory Examinations, TMA is completed at home and submitted before the
  prescribed deadline.
</Callout>

## Subject-wise Assignments

A separate TMA is generally required for each subject.

For example:

| Subject     | TMA Required |
| ----------- | :----------: |
| English     |     Yes      |
| Physics     |     Yes      |
| Chemistry   |     Yes      |
| History     |     Yes      |
| Mathematics |     Yes      |

<Callout type="idea">
  Learners should complete and submit TMAs for all applicable subjects to avoid
  losing marks that contribute to the final result.
</Callout>

## TMA vs Other Assessments

| Assessment                | Purpose                                                       |
| ------------------------- | ------------------------------------------------------------- |
| TMA                       | Home-based assignment work                                    |
| Theory Examination        | Written examination                                           |
| Practical Examination     | Practical skills evaluation                                   |
| Formative Assessment (FA) | Practical assessment component for eligible Stream 1 learners |

<Callout type="warning">
  TMA should not be confused with Formative Assessment (FA). They are separate
  assessment components and serve different purposes within the NIOS evaluation
  system.
</Callout>

## Common Misconceptions

### "Can I Skip TMA?"

No. Learners should complete and submit TMAs for all applicable subjects.

### "Is TMA the Same as an Examination?"

No. TMA is a home-based assignment, while examinations are conducted at
designated examination centres.

### "Is TMA the Same as Formative Assessment?"

No. TMA and Formative Assessment (FA) are completely separate components of the
NIOS assessment system.
