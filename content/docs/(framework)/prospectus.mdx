Browse and download official NIOS prospectuses from different academic sessions.

Each prospectus contains information about admissions, eligibility, subjects, examinations, fees, learner support services, and other important policies applicable to that session.

<Callout type="tip">
  Looking for the latest rules? Start with the newest prospectus and then check
  the Notifications section for any updates issued afterward.
</Callout>

## Before Using an Older Prospectus

- Admission rules may have changed.
- Fee structures may have been revised.
- Subjects and programmes may have been updated.
- Examination policies may differ from current regulations.

<Callout type="warning">
  Older prospectuses are useful for reference and historical information, but
  current admissions and examinations should always be verified using the latest
  prospectus and official notifications.
</Callout>
