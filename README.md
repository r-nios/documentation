# r-NIOS Documentation

A community-driven documentation project dedicated to the **National Institute of Open Schooling (NIOS)**.

This project aims to provide clear, structured, and learner-friendly documentation covering admissions, examinations, practicals, study materials, student services, results, certifications, and other NIOS-related topics.

> [!WARNING]
> This project is **not affiliated with, endorsed by, or operated by NIOS**. It is an independent documentation initiative created to help learners better understand NIOS procedures and services.

## Features

- 📚 Comprehensive NIOS documentation
- 🎓 Admission guides for all streams
- 📝 Examination and assessment information
- 🧪 Practical subjects and practical examination guides
- 📖 Study materials and syllabus resources
- 🏫 Study Centre and PCP information
- 📄 Student services and certificates
- 🔍 Searchable documentation
- 📱 Responsive design

## Project Structure

| Directory               | Description                     |
| ----------------------- | ------------------------------- |
| `app/docs`              | Documentation pages and content |
| `app/(home)`            | Homepage and landing pages      |
| `app/api/search`        | Search functionality            |
| `content/docs`          | Documentation source files      |
| `lib/source.ts`         | Content source adapter          |
| `lib/layout.shared.tsx` | Shared layout configuration     |

## Development

Start the development server:

```bash
npm run dev
```

or

```bash
pnpm dev
```

or

```bash
yarn dev
```

Open:

```text
http://localhost:3000
```

## Contributing

Contributions are welcome.

You can help by:

- Fixing errors and outdated information
- Improving documentation quality
- Adding missing NIOS procedures and services
- Reporting inaccuracies
- Improving page structure and navigation

Before contributing, please verify information using official NIOS sources whenever possible.

## Disclaimer

While every effort is made to keep the documentation accurate and up to date, errors may occasionally occur.

Learners should always verify critical information such as:

- Admission rules
- Eligibility criteria
- Fee structures
- Examination schedules
- Result procedures
- Student service policies

through official NIOS notifications, circulars, portals, and publications.

Official NIOS Website:

https://www.nios.ac.in
